.. note::

    The images are compressed using XZ. You can use `7zip <https://www.7-zip.org/>`_ or
    `WinRAR <https://www.win-rar.com/>`_ to extract the file.

    For **Linux**, you can use the following command to extract the image:

    .. code-block:: console

        xz -d <image_name>.xz
